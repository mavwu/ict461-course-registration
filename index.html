01 / Course overview

A practical course
for thoughtful makers.

ICT461 introduces the tools and habits behind dependable web products. You will move from a clear brief to a working, tested interface while practising the standards that make the web inclusive and resilient.

Expect studio-based work, short critiques and a final project that connects structure, style and behaviour.
