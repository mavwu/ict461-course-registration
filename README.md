# ICT461 Course Registration

A one-page course registration interface built with semantic HTML, responsive CSS and vanilla JavaScript validation.

## Run locally

Open `index.html` directly in a browser, or serve this folder with a local development server:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

## Assignment evidence

- `index.html` — semantic page structure and labelled form controls
- `styles.css` — responsive layout, visual design and focus states
- `script.js` — client-side validation and confirmation interaction
